Source: https://app.notion.com/p/3051199ccfe380caa130d2a1508f11e5

## 📄 How to Build a Strong Resume — Complete Guide

---

### 🎯 Goal of a Resume

> A resume is not your life story.
It is a **marketing document** designed to get you an interview.

A recruiter spends **6–10 seconds** scanning a resume initially. Your resume must instantly answer:

- Who are you?

- What do you do?

- How good are you?

- Why should we interview you?

---

## 🧱 Resume Structure (Ideal Order)

```
Name
ContactInfo
Headline /Summary
Skills
Experience
Projects
Education
Extras (Awards, Certifications)
```

---

## 1️⃣ Resume File Naming — FIRST IMPRESSION

#### ✅ Good Naming

```
Vasanth_Frontend_Developer_5Y.pdf
Anita_SDE_React_Node.pdf
Rahul_Product_Designer.pdf
```

#### ❌ Bad Naming

```
resume.pdf
finalresume.pdf
resume_new_latest_final2.pdf
mycv.docx
```

📌 Rule:

**Name + Role + Experience**

---

## 2️⃣ Header Section

#### ✅ Must Include

- Full Name

- Phone

- Email

- LinkedIn

- Portfolio/GitHub (if relevant)

#### ❌ Avoid

- Full address

- Father’s name

- Date of birth

- Marital status

- Photo (unless design/acting roles)

---

## 3️⃣ Headline / Summary

#### ❌ Bad

> Hardworking developer looking for opportunity to grow.

#### ✅ Good

> Frontend Developer with 4 years experience building scalable React applications used by 200k+ users.

**Formula**

```
Role + Years +Key Tech + Impact
```

---

## 4️⃣ Skills Section

#### ❌ Bad Practice

Listing every skill ever touched.

```
HTML CSS JS React Angular Vue Python Java C++ AWS Docker Kubernetes ML AI Blockchain
```

#### ✅ Good Practice

Group and prioritize:

**Languages:** JavaScript, TypeScript

**Frontend:** React, Redux, Next.js

**Backend:** Node.js, Express

**Tools:** Git, Docker, Jest

📌 Rule:

Only list skills you can confidently answer interview questions about.

---

## 5️⃣ Experience Section — MOST IMPORTANT

#### Golden Rule

> Recruiters care about IMPACT, not RESPONSIBILITIES.

---

#### ❌ Bad Bullet

> Responsible for building UI components.

#### ✅ Good Bullet

> Built reusable React components reducing development time by 35% across 4 teams.

---

#### Bullet Formula

```
Action Verb +Task + Tool + Impact + Metric
```

Examples:

- Reduced bundle size by 42% using code splitting.

- Improved page load speed from 4.5s → 1.2s.

- Led migration from class components to hooks for 60+ components.

---

## 6️⃣ Quantification — SECRET WEAPON

If you don’t quantify → recruiter assumes average work.

#### Examples of Metrics

- %

- Time saved

- Revenue impact

- User count

- Performance improvement

- Team size

- Feature adoption

---

#### ❌ Without Numbers

> Optimized application performance.

#### ✅ With Numbers

> Optimized application performance improving LCP from 3.2s to 1.1s.

---

## 7️⃣ Projects Section

Especially important for:

- Students

- Career switchers

- <3 years experience

#### Each Project Must Include

- What problem it solves

- Tech used

- Scale

- Unique challenge

- Link
