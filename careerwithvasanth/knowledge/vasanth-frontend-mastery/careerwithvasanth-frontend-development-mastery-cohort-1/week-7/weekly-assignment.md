# Weekly assignment

Source: https://app.notion.com/p/30f1199ccfe380c69347d0aea9b5cfd2

### 🧩 Systems to Design

You will perform the same exercise for each of the following systems:

1. **Code Sandbox Platform** (like CodePen / Replit)

1. **E-commerce Application** (like Amazon / Flipkart)

1. **Video Streaming Platform** (like YouTube)

1. **Seat Booking System** (like BookMyShow)

---

### 📝 What You Need to Do (For Each System)

#### 1️⃣ List Functional Requirements

Identify what features the system must provide to users.

Examples:

- Core capabilities

- User interactions

- Primary workflows

---

#### 2️⃣ List Non-Functional Requirements

Define system quality expectations such as:

- Performance

- Scalability

- Reliability

- Availability

- Security

- Consistency

---

#### 3️⃣ Solve Top Functional Design Problems

From your functional list:

- Pick the **top 4 most important functional challenges**

- Explain **how you would design a solution**

- Include architecture thinking, components, and flow

Examples:

- Real-time execution (code sandbox)

- Product search (e-commerce)

- Video recommendation (streaming)

- Concurrent seat locking (booking)

---

#### 4️⃣ Solve Top Non-Functional Design Problems

From your non-functional list:

- Pick **top 2 critical non-functional concerns **

- Provide **design solutions**

- Each system must focus on **different non-functional priorities (So that overall you will cover most non-functional requirements)**

Examples:

- Scalability strategy

- Low latency delivery

- High availability architecture

- Consistency handling

- Fault tolerance
