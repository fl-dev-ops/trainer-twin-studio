title: "Sessions"
description: "Read practice sessions and their results."
---

A session is a learner's practice run against a published role-play scenario. Sessions happen in the TrainerTwin app — learners start them from their assignment link or the learner portal. The API is **read-only** for sessions: list them and read their results.

A few things shape a session:

- A learner starts a role play from its assignment link, as many times as they like: each practice is a new session with the same `assignmentId`.
- A learner's call uses their credits (1 credit = 1 minute) and ends when they run out; it needs at least 5 to start. Admins' and team members' voice calls use the organization's credits.
- A learner has one call at a time in your organization: starting another ends the open one.

See [Role plays end to end](/guides/role-plays).

## List sessions

Combine any of these filters:

| Parameter | Description |
| --- | --- |
| `userId` | Sessions for one learner |
| `scenario` | Sessions for one published scenario slug |
| `assignmentId` | Every practice of one assignment |
| `status` | `assigned`, `activating`, `active`, `completed`, `abandoned`, `failed`, or `revoked` |
| `from` | Started at or after this ISO 8601 timestamp |
| `to` | Started at or before this ISO 8601 timestamp |
| `limit` | Page size, `1`–`100` (default `50`) |
| `offset` | Records to skip (default `0`) |

```bash
curl "https://dash.trainertwin.com/api/v1/sessions?userId=user_123&status=completed&from=2026-09-01T00:00:00Z&to=2026-09-30T23:59:59Z&limit=25" \
  --header "x-api-key: $TRAINERTWIN_API_KEY"
```

Results are sorted by creation time, newest first. The response includes pagination metadata — page through by increasing `offset` until `offset >= total`:

```json
{
  "sessions": [
    {
      "id": "session_123",
      "userId": "user_123",
      "personaSlug": "…",
      "personaVersion": 4,
      "agentSlug": "react-mock-interview",
      "agentVersion": 3,
      "status": "completed",
      "mode": "voice",
      "contextName": "Resume.pdf",
      "createdAt": "2026-09-02T10:00:00.000Z",
      "startedAt": "2026-09-02T10:01:00.000Z",
      "endedAt": "2026-09-02T10:30:00.000Z"
    }
  ],
  "pagination": {
    "limit": 25,
    "offset": 0,
    "total": 42
  }
}
```

The list response contains session metadata without transcript or evidence payloads. Fetch one session for the full result.

## Get session results

```bash
curl "https://dash.trainertwin.com/api/v1/sessions/session_123" \
  --header "x-api-key: $TRAINERTWIN_API_KEY"
```

The detail response includes:

- Pinned persona and scenario versions.
- Session status, delivery mode, and timestamps.
- Transcript data when available.
- Evidence data when available.
- `audioUrl` and `videoUrl` — presigned download URLs for the audio and video recordings, valid for one hour (`null` when that recording doesn't exist).

`startedAt` is `null` for a session the learner has not started yet (for example `assigned` or `failed` before it began).
