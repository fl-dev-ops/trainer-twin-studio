---
title: "Users"
description: "Invite, list, update, and remove learners in your organization."
---

The users API manages learners, not trainers. Creating a user sends an organization invitation instead of creating an account with a password: the email, **Join *your organization* on TrainerTwin**, links to your organization's home page, where the learner continues with Google using the invited email.

To give someone a role play, you don't need to invite them first: [assign](/guides/assignments) it to their email. Inviting them as well sends a second email.

## Invite a learner

```bash
curl "https://dash.trainertwin.com/api/v1/users" \
  --request POST \
  --header "x-api-key: $TRAINERTWIN_API_KEY" \
  --header "content-type: application/json" \
  --data '{ "email": "learner@example.com" }'
```

The response includes the invitation and whether its email was delivered.

```json
{
  "invitation": {
    "id": "invitation_123",
    "email": "learner@example.com",
    "status": "pending",
    "expiresAt": "2026-09-03T09:30:00.000Z"
  },
  "emailSent": true
}
```

<Note>
  A delivery failure does not remove the invitation. Read `emailSent` and handle follow-up in your platform.
</Note>

Inviting an existing learner returns `409`. Re-inviting a pending email refreshes that invitation's expiry.

A new learner gets **30 credits** (1 credit = 1 minute of practice) from your organization's prepaid balance. Credits are shared by every twin and role play and are used by the second during calls; learners see them as minutes. When the balance can't cover a new learner, the invite returns `409`; contact TrainerTwin to top it up. Give a learner more credits in the dashboard (**Users**, or the learner's page).

## List learners

```bash
curl "https://dash.trainertwin.com/api/v1/users?limit=50&offset=0" \
  --header "x-api-key: $TRAINERTWIN_API_KEY"
```

The response contains accepted learners in `users` and outstanding invitations in `invitations`.

## Update a learner name

```bash
curl "https://dash.trainertwin.com/api/v1/users/user_123" \
  --request PATCH \
  --header "x-api-key: $TRAINERTWIN_API_KEY" \
  --header "content-type: application/json" \
  --data '{ "name": "Avery Patel" }'
```

Email and organization role changes are not supported through this endpoint.

## Remove a learner

```bash
curl "https://dash.trainertwin.com/api/v1/users/user_123" \
  --request DELETE \
  --header "x-api-key: $TRAINERTWIN_API_KEY"
```

A successful removal returns `204 No Content`. Nothing is deleted: the learner is disabled — signed out and unable to sign in, with pending assignments cancelled and open sessions ended. Their account and historical sessions are kept. A removed learner no longer appears in list or detail responses; an organization trainer can re-enable them from Settings → Team and users.
