# TrainerTwin API docs

Mintlify documentation for TrainerTwin's organization API.

```bash
cd docs
bun install
bun dev
```

The local site runs at `https://docs.trainertwin.localhost` through Portless.

Validate before publishing:

```bash
bun run validate
bun run check:links
bun run check:a11y
```

Connect the `docs` directory to a Mintlify project for deployment.
