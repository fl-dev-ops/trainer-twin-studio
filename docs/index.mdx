## Base URL

```text
https://trainertwin.com/api/v1
```

All requests and responses use JSON unless the endpoint returns `204 No Content`.

<Note>
  The API is designed for server-to-server integrations. Never expose an API key in browser or mobile application code.
</Note>

## What the API covers

| Resource | Use it to |
| --- | --- |
| Users | Invite and manage learners in your organization |
| Assignments | Assign existing published scenarios to learners |
| Sessions | Read results and manage practice-session records |

Scenario, persona, domain, knowledge, and voice configuration remain dashboard-only.
