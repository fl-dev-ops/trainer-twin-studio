## Base URL

```text
https://dash.trainertwin.com/api/v1
```

All requests and responses use JSON unless the endpoint returns `204 No Content`.

<Note>
  The API is designed for server-to-server integrations. Never expose an API key in browser or mobile application code.
</Note>

## What the API covers

| Resource | Use it to |
| --- | --- |
| Users | Invite and manage learners in your organization |
| Scenarios | List published role-play scenarios and read their configuration (read-only) |
| Assignments | Give learners published scenarios to practise, one attempt each |
| Sessions | List sessions and read their results (read-only) |

The API covers role plays only: twins are not listed and their sessions are not returned. Scenario, persona, knowledge, and voice configuration remain dashboard-only.
