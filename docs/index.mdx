## Base URL

```text
https://dash.trainertwin.com/api/v1
```

Requests and responses are JSON, except `204 No Content`.

<Note>
  Call this API from your server. Never put an API key in a browser, mobile app, or public repository.
</Note>

## What you can do

| You want | Product name | Request |
| --- | --- | --- |
| See published role plays | Role play | `GET /scenarios` |
| Add or list learners | Learner | `POST /users`, `GET /users` |
| See credits still available to allocate | Credits | `GET /credits` |
| Give a learner more credits | Credits | `POST /users/{id}/credits` |
| Give a learner a role play | Assignment | `POST /assignments` |
| Read a finished practice | Session | `GET /sessions/{id}` |

The walkthrough is [Practice flow](/guides/role-plays). Creating a role play, buying credits, and running the call stay in the [TrainerTwin dashboard](https://dash.trainertwin.com). Twins are not in this API.
